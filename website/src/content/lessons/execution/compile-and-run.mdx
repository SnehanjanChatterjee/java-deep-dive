## Give the computer one instruction

A program is a set of instructions. Our first program writes a line to the terminal. Java source is text in a `.java` file; a compiler checks it and produces a `.class` file that the Java virtual machine (JVM) can execute. The JDK supplies both the compiler, `javac`, and the launcher, `java`.

Install a JDK, rather than only a runtime. Open a terminal and run `java -version` and `javac -version`. Both must be available and should select the intended JDK. If a command is missing, follow the JDK installation instructions linked below to configure the executable search path. An editor saves source text; a terminal runs commands. An IDE combines these tools but still needs a selected JDK.

## Save, compile and run HelloJava

Save this source as `HelloJava.java` in an otherwise empty working directory. Use a plain text editor and retain the `.java` extension.

<JavaExample file="HelloJava.java" output={"Hello, Java!"} />

Run these commands **from that directory**:

```bash
javac HelloJava.java
java HelloJava
```

The first command creates `HelloJava.class`. The second names the class to launch; it does not take `.class` as a filename suffix. The line shown under OUTPUT is printed by the Java program, not typed as another terminal command. Re-running the program repeats the instruction; editing the source requires recompiling before this class-launch command sees the change.

## Read the source from the outside inward

`class HelloJava` names a class, a container for Java members. `public` makes the class accessible; the public class name and source filename must agree. `final` prevents subclassing; inheritance is taught later. Braces delimit bodies. The `/** ... */` text is a documentation comment and does not run.

`main` is the entry method used here. Its `String[] args` parameter receives command-line arguments; leave this conventional declaration intact while learning the statements inside it. `static` allows the launcher to call this method without constructing a HelloJava object. `void` means the method returns no value.

`System.out.println("Hello, Java!");` calls an existing output method. The text between double quotes is a String literal. The semicolon ends this statement. Program execution enters main, prints the line, reaches the closing brace and returns to the launcher.

## Distinguish a compiler failure from a running program

Delete the closing quote or semicolon and compile again: a syntax error prevents successful compilation. The compiler identifies a source location, but the actual mistake can occur just before it. Restore the source, compile successfully and then launch. A successful compilation alone is not program output.

If the launcher cannot find HelloJava, check the working directory, spelling/case and presence of the newly compiled class. A stale `.class` file can survive an unsuccessful compilation; do not interpret running that old artifact as evidence the changed source compiled.

## Practice: print two lines

Change main to print your chosen name, then `Learning Java`. Predict the output, compile and run.

<details>
<summary>One complete body and its reasoning</summary>

```java
System.out.println("Ada");
System.out.println("Learning Java");
```

The statements execute in source order and each println ends its line. The result is `Ada` followed by `Learning Java` on the next line. There is no loop: each statement runs once. Changing only the source while launching the old class still prints the previous result.
